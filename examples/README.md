# Exemplos

`galaxy-a35/` traz os tres relatorios reais gerados pelo script ao trocar o `system` de uma
super de Galaxy A35 por uma GSI:

- `super_original_lpdump.txt` — super stock (formato `lpdump` + extras com SHA-256)
- `super_new_lpdump.txt` — super remontada
- `super_validacao.txt` — tabela campo a campo e veredito
